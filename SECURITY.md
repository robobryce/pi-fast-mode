# Security Policy

## Supported versions

Security fixes are applied to the latest commit on `main`. Older commits and tags are not maintained separately.

## Report a vulnerability

Please do not disclose suspected vulnerabilities in a public issue or discussion. Use [GitHub private vulnerability reporting](https://github.com/robobryce/pi-fast-mode/security/advisories/new) to send a confidential report.

Include the affected commit or version, impact, reproduction steps or a proof of concept, and any suggested mitigation. Reports will be assessed privately before coordinated disclosure.
